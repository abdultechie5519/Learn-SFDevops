Page Layouts & Record Types (Short & Simple)

Interviewer: *What are Page Layouts and Record Types in Salesforce?*

📄 Page Layout

Answer:
A Page Layout controls which fields, buttons, related lists, and sections are visible and editable for users.

Funny Example: 😂
Think of a restaurant menu 🍽️.

* Kids' menu 👶 has simple items.
* Adults' menu 👨 has all items.

The food (data) is the same, but the layout shown is different.

👉 Page Layout = How the page looks.

---

🏷️ Record Type

Answer:
A Record Type lets you create different business processes, picklist values, and page layouts for the same object.

Funny Example: 😂
Imagine a movie ticket counter 🎬:

* 🎟️ Regular Ticket
* ⭐ VIP Ticket

Same movie, but different rules and experience.

👉 Record Type = Different types of records with different processes.

---

🎯 Easy Difference

| Record Type                           | Page Layout                        |
| ------------------------------------- | ---------------------------------- |
| Decides what type of record it is | Decides how the page looks     |
| Can have different business processes | Controls fields, buttons, sections |
| Can assign different page layouts     | Cannot change the business process |

---

🧠 One-Line Interview Summary

> "Record Types are used to support different business processes and assign different page layouts, while Page Layouts control how the record page is displayed, including fields, buttons, and related lists."

💡 Super Memory Trick

* 🏷️ Record Type = Different Ticket (VIP vs Regular)
* 📄 Page Layout = Different Menu/Card Design
