🏖️ Salesforce Sandbox (Practice Environment)

What is it?
A Sandbox is a copy of your Salesforce Production where you can safely test and practice without affecting real business data.

Funny Example: 😂
Sandbox = Video game Practice Mode 🎮
You can crash the car, lose the race, or try crazy tricks—no one cares because it's just practice!

#Types of Sandbox

| Type              | Data                           | Storage                                   | Funny Example                              |
| ----------------- | ------------------------------ | ----------------------------------------- | ------------------------------------------ |
| Developer     | Metadata only                  | 200 MB data + 200 MB files            | Your tiny practice notebook 📒             |
| Developer Pro | Metadata only                  | 1 GB data + 1 GB files                | Bigger notebook with more pages 📚         |
| Partial Copy  | Metadata + Sample Data         | 5 GB data + files (based on template) | Trailer of a movie 🎬 (not the full movie) |
| Full Sandbox  | Metadata + All Production Data | Same as Production                        | Full rehearsal before the wedding 💍       |

---

🌍 Production (Live Environment)

What is it?
The real Salesforce where actual customers, employees, and business work happens.

Funny Example: 😂
Production = Real Wedding 💒
If you make a mistake here, everyone notices!

---

🚀 Go Live

What is it?
Moving tested changes from Sandbox → Production.

Funny Example: 😂
You practiced cooking in your kitchen (Sandbox) 🍳.
Now you open your restaurant (Production) 🍽️. That's Go Live!

---

🧠 Easy Memory Trick

* 🏖️ Sandbox = Practice
* 🧪 Developer = Small Practice
* 📚 Developer Pro = Bigger Practice
* 🎬 Partial Copy = Sample Data
* 🎥 Full Sandbox = Complete Copy
* 🌍 Production = Real Business
* 🚀 Go Live = Launch to Customers

URLs

* Production: `https://login.salesforce.com`
* Sandbox: `https://test.salesforce.com`

One-line memory:
"Practice in Sandbox, test everything, then Go Live to Production—just like rehearsing before performing on the real stage!" 🎭
